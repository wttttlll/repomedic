# Academic PPT Generator

## Goal
Create an editable PowerPoint presentation matching
the user's scientific research presentation style.

## Visual style
- Slide ratio: 16:9.
- Background: #FFFFFF.
- Title bar: #061E55.
- Content bars: #243D67.
- Highlight color: #FFBC00.
- Use clear, consistent typography.
- Use English unless requested otherwise.

## Slide layouts
1. Title page
2. Outline page
3. Research background
4. Methodology and flowcharts
5. Experimental results
6. Figure and table comparisons
7. Conclusions and outlook

## Workflow
1. Understand the topic, content and slide count.
2. Convert the content into structured slide data.
3. Choose layouts for individual slides.
4. Call the registered PPT generation tool.
5. Save the output as a .pptx file.
6. Validate the file and slide count.
7. Render and inspect if rendering is available.
8. Report the output path and verification status.

## Quality rules
- Never invent research data or citations.
- Prefer editable text, shapes and charts.
- Never flatten entire slides into images.
- Prevent overlap, clipping and overflow.
- Preserve the reference style consistently.
- Never claim success without tool confirmation.
